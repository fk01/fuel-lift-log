# Intent: รีวิว user story หน้าเวท (หลังเพิ่มยิมหลายที่)

## Story ที่ใช้รีวิว
"เปิดแอป → รู้ว่าวันนี้ต้องทำอะไร ที่ไหน → กดเริ่ม → เล่นจบ → บันทึก" ด้วยมือเดียวในยิม

## ปัญหาที่เจอ (เรียงตามผลกระทบ)
1. **ถามสถานที่ทุกวัน แม้วันวิ่ง/ตีแบด/วันพัก** — กั้นหน้าเวทโดยไม่จำเป็น
2. **หน้าเลือกสถานที่ไม่บอกว่าวันนี้ต้องเล่นอะไร** — ต้องเลือกก่อนถึงรู้ว่าเป็น Pull A
3. **ระหว่างเล่นไม่รู้ว่าอยู่ที่ไหน** และท่าที่แปลงมาไม่มีป้าย / ไม่มีทางสลับกลับเป็นท่าเดิม
4. **รายการโปรแกรมไม่บอกสถานที่** — หัวข้อ "เวทเทรนนิ่ง" เหมือนกันทั้งยิมและคอนโด
5. **คำอธิบายโปรแกรมคอนโดยังเป็นของยิม** ("+ Squat", "+ Deadlift") ทั้งที่ท่าเป็น Goblet Squat / DB RDL
6. **จัดการโปรแกรม: ปุ่ม 4 ปุ่มต่อแถว** (↑ ↓ ⇄ 🗑) แน่นและ ⇄ อ่านไม่ออกว่าคือ "คัดลอก/ย้าย"

## หลังแก้ผู้ใช้จะ
- วันที่ไม่ใช่วันเวท เข้าการ์ดวันนี้ได้ทันที — ถามสถานที่เฉพาะตอนจะเริ่มเวท
- หน้าเลือกสถานที่มีบรรทัด "วันนี้: Pull A · 7 ท่า" และแตะสถานที่ = เข้าไปพร้อมเริ่มได้
- ระหว่างเล่นเห็น `🏠 คอนโด` ที่แถบบน, ท่าที่แปลงมีป้าย "แปลงแล้ว"
- หัวรายการโปรแกรม = `โปรแกรม · 🏠 คอนโด ⌄` (แตะเปลี่ยนที่ได้)
- คำอธิบายโปรแกรมที่แปลงแล้วสร้างใหม่จากกลุ่มกล้ามจริง
- จัดการโปรแกรม: แถวละ 1 ปุ่ม ••• → เมนูมีป้ายชัด (เลื่อนขึ้น/ลง · คัดลอกไป… · ย้ายไป… · ลบ)

## เกณฑ์สำเร็จ
- [ ] วันวิ่ง/แบด/พัก ไม่เจอหน้าเลือกสถานที่
- [ ] วันเวท: จากเปิดแท็บถึงกดเริ่ม ≤ 2 แตะ
- [ ] ทุกจอในเวทบอกได้ว่าอยู่สถานที่ไหน

## นอกขอบเขต
- น้ำหนักแนะนำตอนย้ายท่ายิม→ดัมเบล (ข้อมูลไม่พอ)
