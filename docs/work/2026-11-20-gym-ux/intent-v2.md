# Intent v2: สถานที่ → โปรแกรมของตัวเอง (เวท / คาร์ดิโอ)

## ฟีดแบ็กจากผู้ใช้
- ไม่ต้องเขียนโชว์ว่าที่ไหน "ทำ…ไม่ได้"
- สร้างสถานที่ → เลือกว่าที่นี้มีโปรแกรมแบบไหน: **เวท**, **คาร์ดิโอ** หรือ **ทั้งคู่**
- ผู้ใช้เขียนโปรแกรมของตัวเองได้ (รวมคาร์ดิโอ)

## หลังเสร็จผู้ใช้จะ
- สร้าง/แก้สถานที่: ชื่อ, แผนที่, ประเภท [เวท] [คาร์ดิโอ] (เลือกได้ทั้งคู่), อุปกรณ์ (ถ้ามีเวท)
- แต่ละสถานที่มีรายการโปรแกรมของตัวเอง:
  - โปรแกรมเวท = ท่า/เซ็ต/ครั้ง (เหมือนเดิม)
  - **โปรแกรมคาร์ดิโอ = สร้างเองได้** ชื่อ + ไอคอน + บันทึกอะไร (ระยะ/เวลา หรือแค่ ✓ ทำแล้ว) เช่น "วิ่ง 10 km", "ตีแบด", "ว่ายน้ำ"
- หน้าเวทของสถานที่แสดงเฉพาะโปรแกรมของที่นั้น — ไม่มีข้อความ "ทำไม่ได้" ใดๆ
- ตารางสัปดาห์ชี้ไปโปรแกรม (เวทหรือคาร์ดิโอ) ของสถานที่ที่เลือก; ถ้าที่นั้นไม่มีโปรแกรมของวันนี้ การ์ดวันนี้แค่แสดงโปรแกรมที่มีให้เลือก

## เกณฑ์สำเร็จ
- [ ] ไม่มีข้อความ "ทำ…ไม่ได้" / ป้ายกิจกรรมในหน้าเลือกสถานที่
- [ ] สร้างสถานที่ใหม่แบบคาร์ดิโออย่างเดียว แล้วเพิ่มโปรแกรม "ว่ายน้ำ" ได้ภายใน 1 นาที
- [ ] วิ่ง/ตีแบดเดิมกลายเป็นโปรแกรมคาร์ดิโอ (วิ่ง: ยิม+คอนโด, ตีแบด: สนามแบด) ประวัติเดิมไม่หาย
- [ ] จัดการโปรแกรม: "+ เพิ่มโปรแกรม" ถามว่า เวท หรือ คาร์ดิโอ

## คงไว้จากรอบนี้
- หน้าเลือกสถานที่มีบรรทัด "วันนี้: …", ป้ายสถานที่ระหว่างเล่น, ป้าย "แปลงแล้ว", เมนู ••• จัดการโปรแกรม, ไม่ถามวันพัก

## นอกขอบเขต
- GPS / นาฬิกา / HR zone สำหรับคาร์ดิโอ
