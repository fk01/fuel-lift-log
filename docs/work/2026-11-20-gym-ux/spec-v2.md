# Spec v2: โปรแกรมเวท / คาร์ดิโอ ต่อสถานที่

## ข้อมูล
- สถานที่: `types:["gym","cardio"]` (แทน `act`); อุปกรณ์ใช้เมื่อมี gym
- โปรแกรม (`PROGS`): เพิ่ม `kind:"cardio"` + `icon`, `track:"dist"|"done"`, `goal` (เช่น 10 km); ไม่มี kind = เวท
- ตาราง: `WEEK` ชี้ slot เดิม (push/pull/…/run/bad) → โปรแกรมของสถานที่ที่ `slot` ตรงกัน
- บันทึกคาร์ดิโอ: log `{date,prog,loc,kind:"cardio",km?,sec?}` (doc `g-<date>-<prog>` เดิม → sync ได้เลย)
- migrate: tags.run/runData/bad เดิม → log คาร์ดิโอ; สร้างโปรแกรม "วิ่ง 10 km" (slot run) ที่ยิม+คอนโด, "ตีแบด" (slot bad) ที่สนามแบด
  - XP/เหรียญ/วันที่ออกกำลังกาย นับจาก log ใหม่ (ตีแบด +50 XP เหมือนเดิม)

## หน้าจอ
1. **แก้ไขสถานที่**: ชิปประเภท `เวท` `คาร์ดิโอ` (เลือกได้ทั้งคู่, อย่างน้อย 1) → อุปกรณ์แสดงเมื่อเลือกเวท
2. **หน้าเลือกสถานที่**: การ์ด = ชื่อ · แผนที่ · `N โปรแกรม` · ล่าสุด (ไม่มีป้ายทำได้/ไม่ได้); ที่ที่มีโปรแกรมของวันนี้ขึ้นก่อน
3. **หน้าเวทของสถานที่**: `🏠 คอนโด ⌄` → ส่วน **เวท** (การ์ดโปรแกรม) และ/หรือ **คาร์ดิโอ** (การ์ดโปรแกรมคาร์ดิโอ) ตามประเภทของที่นั้น
4. **การ์ดวันนี้**: มีโปรแกรมตามตาราง → ปุ่มเริ่ม/บันทึก; ไม่มี → `วันนี้: ตีแบด` + ชิปโปรแกรมของที่นี้ให้แตะเริ่ม (ไม่มีข้อความทำไม่ได้)
5. **+ เพิ่มโปรแกรม** → เลือก `🏋️ เวท` / `🏃 คาร์ดิโอ` (เฉพาะประเภทที่สถานที่มี)
6. **แก้โปรแกรมคาร์ดิโอ**: ไอคอน, ชื่อ, บันทึก `ระยะ + เวลา` | `✓ ทำแล้ว`, เป้าหมาย (km, ไม่บังคับ), วันในตาราง (ไม่บังคับ)
7. **บันทึกคาร์ดิโอ**: แบบระยะ → แผ่นวิ่งเดิม (km/เวลา/pace); แบบ ✓ → ยืนยันเหมือนตีแบดเดิม

## เอาออก
- ป้าย "ทำ…ไม่ได้", ปุ่ม "เวทแทน/วิ่งแทน", ชิปกิจกรรม, การ์ดวิ่ง/ตีแบดแบบตายตัว
