# Spec: UX หน้าเวท + คาร์ดิโอตามสถานที่

## หน้าจอ / พฤติกรรม
1. **ข้อมูลสถานที่** เพิ่ม `act:["gym","run","bad"]` (ชิป "กิจกรรม" ในชีตแก้ไขสถานที่; ชิปอุปกรณ์แสดงเมื่อเลือก "เวท")
   - migrate: ยิม/คอนโด = gym+run, เพิ่ม 🏸 สนามแบด (bad, ไม่มีอุปกรณ์)
2. **หน้าเลือกสถานที่**
   - บรรทัดบน: `วันนี้: Pull A · 7 ท่า` / `วันนี้: 🏸 ตีแบด` / `วันนี้: 🏃 วิ่ง 10 km`
   - เรียง: ที่ที่ทำแผนวันนี้ได้ก่อน (ล่าสุดก่อน) → ที่ที่ทำไม่ได้ขึ้นจาง + `ทำ<กิจกรรม>ไม่ได้`
   - วันพัก หรือทำครบแล้ววันนี้ → ไม่แสดงหน้าเลือก (ใช้ที่ล่าสุด)
   - แตะสถานที่ → การ์ดวันนี้พร้อมปุ่มเริ่ม (รวม 2 แตะ)
3. **การ์ดวันนี้** ถ้าที่ปัจจุบันทำแผนไม่ได้: `🏸 ตีแบด — ทำที่ 🏠 คอนโดไม่ได้` + ปุ่มรอง `เปลี่ยนที่` และทางเลือกที่ทำได้ (`▶ เวท: Push A` / `🏃 วิ่ง`)
4. **รายการโปรแกรม** หัว `โปรแกรม · 🏠 คอนโด ⌄`; การ์ดคาร์ดิโอเฉพาะกิจกรรมที่ที่นี้ทำได้ (ไม่มีเวท → ซ่อนส่วนโปรแกรม)
5. **ระหว่างเล่น** แถบบน (wo-bar) มีป้าย `🏠 คอนโด`; การ์ดท่ามีป้าย `แปลงแล้ว` ถ้า `swap`
6. **คำอธิบายโปรแกรม** ที่แปลงแล้ว: สร้างใหม่ = วันตามตาราง + กลุ่มกล้ามหลัก (เช่น `พ. · หลัง แขน ขา แกนกลาง`)
7. **จัดการโปรแกรม** แถวละปุ่ม ••• → แผ่นเมนู: เลื่อนขึ้น · เลื่อนลง · คัดลอกไป… · ย้ายไป… · ลบ (ลบถามยืนยัน)

## ข้อมูล
- `LOCS[i].act` (ไม่มี = ["gym","run"]); sync ไปกับ locs เดิม
- วิ่ง/ตีแบด บันทึก `tags.runLoc` / `tags.badLoc` (ไว้ดูภายหลัง ไม่แสดงตอนนี้)

## ข้อความ
วันนี้: / Today: · ทำ…ไม่ได้ / Can't … here · เปลี่ยนที่ / Change place · กิจกรรม / Activities · เลื่อนขึ้น / Move up · เลื่อนลง / Move down

## กรณีพิเศษ
- ไม่มีที่ไหนทำแผนวันนี้ได้ → แสดงทุกที่ปกติ + ข้อความ "ยังไม่มีที่ที่ตีแบดได้ · เพิ่มสถานที่"
- ย้อนดูวันอื่น (DAY≠TODAY) ไม่ถาม
