# Spec: ปุ่มกดง่าย ≥ 44px

## หน้าจอ / พฤติกรรม
บล็อกเดียวท้าย `app.css` "Touch floor" (ชนะ rule เก่าตามลำดับ, ไม่ต้อง !important):

| ตัว | ตอนนี้ | วิธี |
|---|---|---|
| `.btn.sm`, `.pc-go`, `.chip`, `.pc-more`, `.day-gear`, `.sh-x` | 31–40 | `min-height:44px` (+ `min-width:44px` ปุ่มไอคอน) — มองเห็นโตขึ้นจริง |
| `.rc-chip`, `.loc-chip` (chip แน่นใน card) | 36 | ขนาดที่เห็นเท่าเดิม, ขยายพื้นที่กดด้วย `::after{inset:-4px}` ให้ถึง 44 |
| `.ec-d` (วันในสัปดาห์) | 42 | `min-height:44px` |
| input 34px บนหน้ากิน | 34 | `min-height:44px` |
| checkbox ใน `.sets` | 22 | ขนาดที่เห็น 24px, ช่อง/แถวทั้งช่องกดติ๊กได้ (label ครอบ) ถ้าโครงสร้างเอื้อ; ไม่งั้น 28px |

ลบ min-height ซ้ำของ `.btn.sm` (บรรทัด 453/790) ให้เหลือที่เดียว.
