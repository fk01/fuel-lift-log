# intent — แป้นกรอกตัวเลข (number pad) เข้าธีม
- ปุ่มก้อนดำทึบ → glass (พื้นโปร่ง + ขอบบาง), ปุ่มที่เลือก = สว่างขึ้น + ขอบขาว
- Clear: เดิมมีกรอบเหลี่ยม → label เปล่า
- ปุ่มยืนยัน: เดิม "✓ เสร็จเซ็ตนี้" ตัวดำบนพื้นดำ อ่านไม่ออก + คำว่า "เซ็ต" ไม่เข้ากับระยะ/เวลา → "✓ Done" (TH: เสร็จ) ขาวหนาชิดขวา
- แถบล่างเป็นแบบ B (เส้นคั่นบน)
- key i18n "เสร็จ" ถูกแปลทับเป็นค่าว่าง/"แก้ไข" ในไฟล์อื่น → ตั้งข้อความปุ่มตรงใน number-pad.js
- ไฟล์: index.html, number-pad.js, glass-cards.css v=57
