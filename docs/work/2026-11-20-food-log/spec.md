# Spec: บันทึกอาหารเอง

## ข้อมูล
- ต่อวัน: `food[date].log = [{id, n, k, p, slot, q}]` (n ชื่อ, k kcal ต่อ 1 เสิร์ฟ, p โปรตีน g, slot `m1|m2|m3|m4|snack`, q จำนวนเสิร์ฟ 0.5–5)
- อยู่ใน doc `f-<date>` เดิม → ซิงก์ D1 ทันทีโดยไม่แก้ server
- "ที่เคยกิน": สร้างจาก log ทุกวัน (ไม่เก็บแยก) เรียงตามครั้งล่าสุด รวมรายการชื่อซ้ำ แสดง 8 รายการ
- ยอดรวมทุกจุด (`dayP`, ประวัติ, กราฟสถิติ, แถบบนหน้าอาหาร) = มื้อในแผนที่ติ๊ก + Σ(k×q, p×q)

## หน้าอาหาร
- ใต้แถบแคล/โปรตีน: ปุ่มทึบ `+ บันทึกอาหาร`
- รายการที่บันทึกเองแสดงเป็นแถวย่อ (ไอคอน ✎ · ชื่อ ×q · kcal · P) ใต้มื้อที่เลือก; `ของว่าง` ต่อท้ายรายการ
- แตะแถว → แผ่นแก้ไข (แก้ค่า / ลบ)
- เป้า kcal ยังคิดจากแผนมื้อ (`kt`) — ตัวเลขที่กินจริงเพิ่มขึ้นตามรายการ

## แผ่น "บันทึกอาหาร"
1. **ที่เคยกิน** (ถ้ามี): ชิปแนวนอนเลื่อนได้ `ข้าวมันไก่ · 600 · P25` → แตะ = กรอกฟอร์มให้
2. ฟอร์ม: ชื่อ (โฟกัสอัตโนมัติ) · kcal · โปรตีน (g) — ช่องตัวเลข `inputmode=decimal`
3. จำนวน: segmented `×0.5 | ×1 | ×1.5 | ×2` (ค่าเริ่ม ×1) + ผลรวมสด "= 900 kcal · P38"
4. มื้อ: ชิป `เช้า · กลางวัน · บ่าย · เย็น · ของว่าง` (ค่าเริ่มตามเวลา: <10:30 เช้า, <14 กลางวัน, <17 บ่าย, <21 เย็น, อื่น ๆ ของว่าง)
5. ปุ่มทึบ `บันทึก` (ติดล่าง) · แก้ไข: + ปุ่มเส้น `ลบ` (กดซ้ำยืนยัน)
- ตรวจ: ต้องมีชื่อ และ kcal หรือโปรตีนอย่างน้อยหนึ่งค่า > 0
