# Intent: บันทึกอาหารเอง (นอกแผนมื้อ)

## ปัญหา
- หน้าอาหารมีแค่แผนมื้อตายตัว (ติ๊กกินแล้ว) — กินอะไรนอกแผน / เปลี่ยนเมนู / กินเพิ่ม บันทึกไม่ได้
- แคล/โปรตีนวันนี้เลยไม่ตรงกับที่กินจริง

## หลังเสร็จผู้ใช้จะ
- กด `+ บันทึกอาหาร` บนหน้าอาหาร → แผ่นล่าง: ชื่อ · kcal · โปรตีน (g) · มื้อ (เช้า/กลางวัน/บ่าย/เย็น/ว่าง — เลือกให้ตามเวลา) → บันทึก
- เลือกจาก **ที่เคยกิน** (ล่าสุด/บ่อยสุด) แตะเดียวเพิ่มได้ + ปรับจำนวนเสิร์ฟ ×0.5 / ×1 / ×2
- รายการที่บันทึกเองแสดงในวันนั้นใต้มื้อที่เลือก แตะเพื่อแก้/ลบ
- แคล/โปรตีนวันนี้, ประวัติโภชนาการ, กราฟในสถิติ › ร่างกาย นับรวมรายการเหล่านี้
- ย้อนบันทึกวันอื่นได้ (ตามวันที่เลือกในแถบวันที่)

## เกณฑ์สำเร็จ
- [ ] บันทึกอาหารใหม่ได้ใน ≤ 3 แตะ + พิมพ์ (ครั้งถัดไปจาก "ที่เคยกิน" = 2 แตะ)
- [ ] ยอดแคล/โปรตีนทุกจุดรวมรายการที่บันทึกเอง
- [ ] ซิงก์ข้ามเครื่องเหมือนข้อมูลอาหารเดิม
- [ ] แผนมื้อเดิมใช้ได้เหมือนเดิม

## นอกขอบเขต
- ฐานข้อมูลอาหาร / สแกนบาร์โค้ด / ถ่ายรูปคำนวณแคล
- คาร์บ / ไขมัน (เก็บแค่ kcal + โปรตีน ตามเป้าที่แอปใช้)
- แก้แผนมื้อตายตัว (งานแยก)
