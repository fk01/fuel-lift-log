# Intent: ปรับ UI ตามรีวิว (สถิติ · เพิ่มเติม · How-to · ภาพรวม)

## สถิติ › ร่างกาย
- [ ] แบ่งเป็นการ์ดชัด: "น้ำหนักตัว" กับ "โภชนาการ" มีระยะห่างและหัวข้อของตัวเอง
- [ ] ค่าล่าสุด 3 ช่อง (น้ำหนัก / มวลกล้าม / ไขมัน) เหลือแถวเดียว ตัวเลขใหญ่ — สถิติย่อย (7 วัน, 30 วัน, ต่อสัปดาห์, เป้าหมาย) ย่อเป็นบรรทัดเดียว
- [ ] ปุ่ม `+ บันทึกร่างกาย` เป็นปุ่มทึบ (primary)
- [ ] ช่วงเวลา (1 เดือน / 3 เดือน / 1 ปี / ทั้งหมด) เป็น segmented control แบบเดียวกับ "การฝึก | ร่างกาย"
- [ ] กราฟ: จุดข้อมูล + ป้ายค่าต่ำสุด/สูงสุด/ล่าสุด

## เพิ่มเติม
- [ ] จัดกลุ่มเมนูมีหัวข้อ: **การฝึก** (คลังท่า, จัดการโปรแกรม, สถานที่, คำนวณ 1RM, เหรียญ) · **ข้อมูล** (ซิงก์, ส่งออก/นำเข้า) · **ตั้งค่า** (ภาษา, Face ID, แจ้งเตือน)
- [ ] แต่ละกลุ่มเป็นการ์ด แถวมีไอคอนเส้น + คำอธิบายรอง (มีอยู่แล้ว ปรับให้เด่นขึ้น)
- [ ] เพิ่มเมนู "สถานที่" (ตอนนี้เข้าได้แค่จากหน้าเลือกสถานที่)
- [ ] จัดการโปรแกรม: แท็บ JSON ย้ายเป็นลิงก์เล็กท้ายหน้า (เครื่องมือขั้นสูง)

## แผ่นคัดลอก/ย้ายโปรแกรม
- [ ] ตัวอักษรใหญ่ขึ้น, แถวละท่า 2 บรรทัด (เดิม → ใหม่) จัดกลุ่มตามกล้าม
- [ ] ท่าที่ไม่เปลี่ยนรวมเป็นบรรทัดเดียว "อีก N ท่าเหมือนเดิม"
- (ไม่ใส่ช่องค้นหา: โปรแกรมหนึ่งมี ≤ 10 ท่า)

## How-to
- [ ] ขั้นตอนเป็นการ์ดเลขใหญ่ "1 2 3" คำแรกของแต่ละขั้นตัวหนา, ระยะห่างระหว่างขั้น
- [ ] ปุ่ม ✕ มุมขวาบนของแผ่น + ปุ่ม "เข้าใจแล้ว" ติดล่างจอ (ทุกแผ่นที่เปิดจากล่าง)

## ภาพรวม
- [ ] กฎปุ่ม: ทึบ = งานหลัก 1 ปุ่มต่อจอ · เส้นขอบ = รอง · ข้อความ = ยกเลิก/ปิด — ไล่ปรับทุกหน้า
- [ ] สเกลตัวอักษรเดียวทุกหน้า (หัวหน้า 28 · หัวข้อ 20 · เนื้อหา 15 · รอง 13) และเช็ก contrast สีเทา ≥ 4.5:1

## หมายเหตุ
- สีหลักของแอปคือสีครีม (ปุ่มทึบ) ส่วนสีส้มในภาพคือปุ่มแชร์ของแผ่นวิ่ง — ปุ่มหลักจะใช้ครีมทึบเพื่อให้ทั้งแอปเป็นชุดเดียว
