# Spec: ปรับ UI ตามรีวิว

## กฎกลาง (ใช้ทุกหน้า)
- ปุ่มทึบครีม `.btn.primary` = งานหลัก 1 ปุ่มต่อจอ/แผ่น · ปุ่มเส้นขอบ `.btn` = รอง · ปุ่มข้อความ `.btn.text` = ปิด/ยกเลิก
- สเกลตัวอักษร: 28 / 20 / 15 / 13 / 12 (token `--fs-*`), `--muted` ≥ 4.5:1 บน `--bg`
- ระยะห่างระหว่างการ์ดในหน้า = 20px, ภายในการ์ด = 16px

## สถิติ › ร่างกาย
- การ์ด **น้ำหนักตัว**: หัวข้อ + ปุ่มทึบ `+ บันทึก` ขวาหัวข้อ
  - แถวค่าล่าสุด 3 ช่อง ตัวเลข 28px (kg / kg / %) + การเปลี่ยนแปลง 30 วัน ใต้ตัวเลข (▲▼ สีเขียว/ส้ม)
  - segmented `1 ด. | 3 ด. | 1 ปี | ทั้งหมด` (สูง 36px, ตัวที่เลือกพื้นครีม)
  - กราฟ: เส้น + จุดทุกค่า, จุดล่าสุดใหญ่ + ป้ายค่า, ป้าย "ต่ำสุด" / "สูงสุด", เส้นตารางจาง 3 เส้น
  - ว่าง: ภาพลายเส้น + "ยังไม่มีบันทึก" + ปุ่มทึบ
- การ์ด **โภชนาการ** แยก (ระยะ 20px)

## เพิ่มเติม
- 3 กลุ่ม หัวข้อเล็กตัวพิมพ์ใหญ่: **การฝึก** · **ข้อมูล** · **ตั้งค่า**; แต่ละกลุ่มเป็นการ์ดเดียว แถวคั่นเส้น
- แถว: ไอคอนเส้นในกรอบมน 36px · ชื่อ 15 · คำอธิบาย 13 · ›
- การฝึก: คลังท่า · จัดการโปรแกรม · **สถานที่** (ใหม่ → ชีตรายการสถานที่ แก้/เพิ่ม) · คำนวณ 1RM · เหรียญรางวัล
- ข้อมูล: ซิงก์ / ดึงข้อมูลล่าสุด · ส่งออก / นำเข้า
- ตั้งค่า: ภาษา · Face ID · แจ้งเตือน
- จัดการโปรแกรม: เอาแท็บ "แบบปุ่ม | แบบ JSON" ออก → ลิงก์ "แก้แบบ JSON (ขั้นสูง)" ท้ายรายการ

## แผ่นคัดลอก/ย้าย
- เลือกสถานที่ (ชิป) → รายการ "จะเปลี่ยน" แต่ละท่า 2 บรรทัด: เดิม (13 เทา, ขีดฆ่า) / ใหม่ (15 ตัวหนา) จัดกลุ่มตามกล้าม
- "✓ อีก N ท่าเหมือนเดิม" บรรทัดเดียว
- โหมด คัดลอก | ย้าย = segmented · ปุ่มทึบล่าง

## แผ่นล่างทุกแผ่น (gen-sheet, prog-sheet, how-to)
- หัวแผ่นติดบน: ชื่อ + ปุ่ม ✕ 44×44 ขวาบน
- How-to: GIF → ขั้นตอนเป็นแถว เลขวงกลม 28px + ข้อความ 15 (วลีแรกก่อน "," ตัวหนา) ระยะ 12px → ปุ่ม `เข้าใจแล้ว` ทึบ ติดล่างแผ่น (sticky)
