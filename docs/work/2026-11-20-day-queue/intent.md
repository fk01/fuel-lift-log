# Intent: "วันนี้จะทำอะไร?" = รายการของวันนี้ (pending → in progress → done)

## ตอนนี้
- วันมีตาราง: เช็กลิสต์ "แผนวันนี้" (✓ เมื่อเสร็จ)
- วันไม่มีตาราง: 3 การ์ด เวท / คาร์ดิโอ / พัก (เลือกได้ทีละอย่าง)

## หลังเสร็จ
```
วันนี้จะทำอะไร?                         1/3
 ✓ Done        🏃 วิ่ง 10 km   คอนโด · 10.2 km
 ▶ In progress 🏋 Push A       ยิม · 12/31 เซ็ต      [กลับไปเล่น]
 ○ Pending     🏸 ตีแบด        สนามแบด               [เริ่ม] [✕]
 + เพิ่มโปรแกรม
 😴 พักวันนี้
```
- รายการเริ่มต้น = โปรแกรมตามตารางวันนี้ (ถ้ามี); วันไม่มีตาราง = ว่าง + ปุ่ม "+ เพิ่มโปรแกรม" เด่น
- **+ เพิ่มโปรแกรม** → แผ่นรายการทุกโปรแกรมแบ่งตามสถานที่ (เวท/คาร์ดิโอ) แตะเพื่อเพิ่มเข้าวันนี้ (เพิ่มได้หลายอัน)
- สถานะแต่ละแถว (ป้าย pill):
  - **Pending** (เทา) — ปุ่ม `▶ เริ่ม` (ไปสถานที่นั้น + เริ่มเลย) · ✕ เอาออกจากวันนี้
  - **In progress** (ฟ้า) — เวทที่กำลังเล่น; ปุ่ม `กลับไปเล่น`
  - **Done** (เขียว) — บันทึกแล้ว + สรุป
- ทำเสร็จหนึ่งอย่าง → กลับมาที่รายการนี้; ทำครบ → "ครบแล้ววันนี้ ✓"
- พักวันนี้ ยังเป็นลิงก์เล็ก (เมื่อยังไม่ได้ทำอะไร)
- ข้อมูล: `dayplan {date, items:[programKey]}` ในเครื่อง (+ ตารางเป็นค่าเริ่ม)
