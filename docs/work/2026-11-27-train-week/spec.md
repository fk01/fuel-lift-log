# Spec
- "This week · done/planned": Mon → Sun rows (week of today).
  - Past: what was logged (✓ done) or planned + "missed" / Rest.
  - Today = glass card: day · **program** · place; tabs when today has more than one item (place name when the same
    program exists at two places); "n exercises · ~min"; first 5 exercises with sets × reps · last weight; bar
    Rest today · Change today | ▶ Start (Log for cardio, Resume when in progress, ✓ Done › when finished).
    Rest day → "Rest day" card with "Train instead ›".
  - Future: program names (deduped) + places; tap → exercises; ⇄ / + → sheet with every program, tick the ones on
    that weekday (writes the program's days — repeats weekly). Cancel | ✓ Save.
- "All programs · n" + Manage ›; one line "Gym 4 · Condo 4 · Anywhere 2 ⌄" unfolds the existing program list.
