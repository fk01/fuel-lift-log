# Spec
- TRAIN · done/total: one row per planned program — **name** · place · time (if Time of day set);
  under it the first 3 exercises + "+n" (cardio: "Cardio"); right ▶ Start / ✓. Tap name → preview.
  Nothing planned: "Rest day / Nothing planned" + Train anyway / Pick ›.
- EAT · done/total + "eaten / goal kcal ›" (→ Eat tab): meals by time with checkboxes; 0-kcal vitamins fold into
  the meal before them ("+ vitamins") and are ticked together; NOW marker; next open meal = bright dot.
- "+ Ate something else".
- MY BODY: existing body card, header renamed, no box/icon.
- No HP/SP/EXP bars.
