# Spec
- Hold the row's number circle and drag: row lifts (solid glass card), other rows slide out of the way, drop places it.
- Near top/bottom edge (above the Unsaved/Save bar) the editor auto-scrolls.
- Tap on the number without moving = nothing.
- Hint under "Time of day": "Hold a number and drag to reorder".
- ⋯ → Move up / Move down stays; every list rebuild keeps height + scroll position (restored again next frame / 80 ms for iOS).
