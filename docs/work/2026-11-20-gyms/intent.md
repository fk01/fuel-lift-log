# Intent: ยิมหลายที่ — ท่าตามอุปกรณ์ + น้ำหนักแยกตามยิม

## ปัญหา
- ไปเล่น 2 ที่: **ยิม** (เครื่องครบ) และ **คอนโด** (มีแต่ดัมเบล)
- โปรแกรมตอนนี้ใช้เครื่อง/เคเบิลเกือบทั้งหมด → ที่คอนโดเล่นตามไม่ได้ ต้องเปลี่ยนท่าเองทุกครั้ง
- เครื่องเดียวกันคนละที่ หน่วย/แผ่นน้ำหนักไม่เท่ากัน → "ครั้งล่าสุด", ใช้ค่าครั้งก่อน, e1RM, กราฟ ปนกันแล้วหลอกตา

## หลังเสร็จผู้ใช้จะ
- เปิดหน้าเวท → เจอ **หน้าเลือกสถานที่ก่อน** "วันนี้ออกที่ไหน?" (ยิม / คอนโด)
- เลือกแล้วเห็น **โปรแกรมของที่นั้น** — แต่ละที่มีชุดโปรแกรมตามอุปกรณ์ที่ระบุไว้ (ยิม = Push/Pull A/B เดิม, คอนโด = ชุดดัมเบล)
- เห็นน้ำหนักครั้งก่อน / e1RM / กราฟ **ของที่นั้น** ไม่ปนกับอีกที่

## เกณฑ์สำเร็จ
- [ ] มีรายการสถานที่ 2 ที่: ยิม (ทุกอุปกรณ์), คอนโด (ดัมเบลอย่างเดียว)
- [ ] **เพิ่ม / แก้ไข / ลบ** สถานที่ได้ (ลบได้เมื่อเหลือ ≥1 ที่; ถามยืนยันก่อน; ประวัติของที่ถูกลบยังอยู่ในสถิติ ไม่หาย)
- [ ] แต่ละสถานที่มี: ชื่อ (ตั้งเองได้ เช่นชื่อยิมจริง), ตำแหน่ง (ปักหมุด/ลิงก์แผนที่ เปิด Maps ได้), อุปกรณ์ที่มี (ดัมเบล, บาร์เบล, เคเบิล, เครื่อง, ม้านั่ง ฯลฯ)
- [ ] หน้าแรกของแท็บเวท = เลือกสถานที่ (ไฮไลต์ที่ใช้ล่าสุด) → เข้าหน้าเวทของที่นั้น, เปลี่ยนที่ได้จากหัวหน้า
- [ ] แต่ละสถานที่มีชุดโปรแกรมของตัวเอง; คอนโดได้ชุดเริ่มต้นแปลงจากโปรแกรมยิมเป็นท่าดัมเบลที่โดนมัดเดียวกัน
- [ ] **คัดลอก / ย้าย** โปรแกรมไปสถานที่อื่นได้ → ท่าที่ไม่มีอุปกรณ์ถูกแปลงเป็นท่าทดแทนอัตโนมัติ (ติดป้าย "แปลงแล้ว") แล้วแก้ต่อได้
- [ ] จัดการโปรแกรม/คลังท่า กรองเฉพาะท่าที่อุปกรณ์ของที่นั้นรองรับ
- [ ] ตารางสัปดาห์ใช้ร่วมกัน (วันอ. = Push A ของที่ที่เลือก)
- [ ] ประวัติแต่ละครั้งบันทึกสถานที่; ครั้งล่าสุด / ใช้ค่าครั้งก่อน / e1RM / กราฟ ใช้ข้อมูลของสถานที่เดียวกัน
- [ ] การฟื้นตัว / เซ็ตต่อกล้าม / วอลุ่ม ยังนับรวมทุกที่
- [ ] ข้อมูล/โปรแกรม/ประวัติที่มีตอนนี้ทั้งหมดย้ายเป็นของสถานที่แรก (ยิม) — ผู้ใช้ตั้งชื่อยิมและใส่ตำแหน่งได้

## นอกขอบเขต (ทำทีหลังได้)
- เลือกสถานที่อัตโนมัติจาก GPS
- ผูกสถานที่กับวันในตาราง
- รูปเครื่องจริงในยิม

## คำถามเปิด (ตอบใน spec)
- ดัมเบลที่คอนโดหนักสุดกี่ kg / เป็นแบบปรับน้ำหนักได้ไหม (ใช้จำกัดคำแนะนำน้ำหนัก)
