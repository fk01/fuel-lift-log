# Spec: ยิมหลายที่

## หน้าจอ / พฤติกรรม
1. **เลือกสถานที่** (หน้าแรกของแท็บเวท เมื่อยังไม่ได้เลือกวันนี้)
   - หัว "วันนี้ออกที่ไหน?" · การ์ดสถานที่ละใบ: ไอคอน, ชื่อ, 📍 แผนที่ (เปิด Maps), สรุปอุปกรณ์, ป้าย "ล่าสุด"
   - แตะการ์ด → เข้าหน้าเวทของที่นั้น (จำไว้ทั้งวัน; วันใหม่ถามใหม่)
   - ปุ่ม "+ เพิ่มสถานที่" · กดค้าง/ปุ่ม ••• ที่การ์ด → แก้ไข
2. **หน้าเวท** — เหมือนเดิม + แถบหัว `🏢 ชื่อสถานที่ ⌄` แตะเพื่อกลับไปเลือกที่ใหม่; การ์ดวันนี้/โปรแกรมแสดงเฉพาะของที่นั้น
3. **แก้ไขสถานที่** (gen-sheet): ไอคอน, ชื่อ, ลิงก์ Google Maps (ปุ่ม "ใช้ตำแหน่งปัจจุบัน"), ชิปอุปกรณ์: ดัมเบล · บาร์เบล · เคเบิล · เครื่อง · ม้านั่ง · บาร์โหน · ยางยืด · ตัวเปล่า(ติดเสมอ), ดัมเบลหนักสุด (kg, ไม่บังคับ), ปุ่มลบ (ยืนยัน; ห้ามลบที่สุดท้าย)
4. **คัดลอก/ย้ายโปรแกรม** — ในแผ่นโปรแกรม ปุ่ม ••• → "คัดลอกไป…" / "ย้ายไป…" → เลือกสถานที่ → แสดงตัวอย่างการแปลง (ท่าเดิม → ท่าใหม่, "ไม่มีท่าแทน → ตัดออก") → ยืนยัน
5. **คลังท่า / เพิ่มท่าในโปรแกรม** กรองตามอุปกรณ์ของสถานที่ (สวิตช์ "แสดงทั้งหมด")

## ข้อมูล (settings doc ใน D1, sync เดิม)
- `locs: [{id,name,icon,map,eq:[...],dbMax}]`, `locCur:{date,id}`
- `progs` เพิ่ม field `loc` ต่อโปรแกรม; ตารางสัปดาห์จับคู่ด้วย slot (push/pull/push2/pull2) → ใช้โปรแกรม slot เดียวกันของสถานที่ปัจจุบัน
- EXLIB ต่อท่า: `eq` (อุปกรณ์ที่ต้องใช้), `sub` (รายการท่าทดแทน); ค่าเริ่มต้นครบทุกท่าในโปรแกรมปัจจุบัน
- log `g-*` เพิ่ม `loc`; ไม่มี = สถานที่แรก. last/load-last/e1RM/กราฟ กรองตาม loc; recovery/วอลุ่ม/เซ็ต รวมทุกที่
- migrate: สร้าง `ยิม` (ทุกอุปกรณ์, โปรแกรมเดิมทั้งหมด) + `คอนโด` (ดัมเบล+ม้านั่ง+ตัวเปล่า, ชุด Push/Pull A/B ที่แปลงแล้ว)

## ข้อความ (TH / EN)
วันนี้ออกที่ไหน? / Where today? · เพิ่มสถานที่ / Add place · ล่าสุด / Last · แปลงแล้ว / Swapped · คัดลอกไป… / Copy to… · ย้ายไป… / Move to… · ลบสถานที่นี้? / Delete this place?

## กรณีพิเศษ
- ลบสถานที่: โปรแกรมของที่นั้นถูกลบด้วย (ถามยืนยัน), ประวัติยังอยู่ แสดงชื่อเดิม
- กำลังเล่นค้าง (draft) → เปิดแท็บเวทข้ามหน้าเลือกไปเล่นต่อเลย
- เครื่องเก่าที่ยังไม่อัปเดต: server merge ตาม progsRev เดิม ไม่ทับ locs
