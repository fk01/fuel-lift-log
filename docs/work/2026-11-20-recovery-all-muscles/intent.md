# Intent: การฟื้นตัวแสดงกล้ามครบทุกมัด

- **ปัญหา:** หน้าการฟื้นตัวแสดงเฉพาะกล้ามที่เคยเล่น (ตอนนี้ 10 จาก 16 มัด) มัดที่ไม่เคยเล่นหรือเล่นนานแล้วหายไปเลย ผู้ใช้เลยไม่รู้ว่าขาดมัดไหน
  - ข้อมูลจริง: Push B 18 พ.ย. บันทึกแค่ 5 ท่าบน ไม่มี Seated Calf / Hip Adduction / Hip Abduction · Push A 13 พ.ย. ไม่มี Leg Extension / Leg Curl
  - จึงไม่ขึ้น: ต้นขาหลัง, น่อง, ขาใน, ขานอก, แขนท่อนล่าง, ข้างลำตัว
- **ทำไม:** อยากเห็นว่ามัดไหนถูกละเลย จะได้เติมในโปรแกรม/วันถัดไป
- **หลังเสร็จผู้ใช้จะ:** เห็นครบ 16 มัดทุกครั้ง พร้อมสถานะ
- **เกณฑ์สำเร็จ:**
  - [ ] แสดงครบ 16 มัด เรียงจาก "ยังไม่เคยเล่น / นานสุด" ขึ้นก่อน หรือตามกลุ่ม (ตัดสินใน spec)
  - [ ] มัดที่ไม่เคยเล่น: สีเทา ป้าย "ยังไม่เคยเล่น"; เล่นเกิน 7 วัน: ป้าย "ละเลย" สีส้มเข้ม
  - [ ] หุ่นระบายมัดที่ถูกละเลยให้เห็นด้วย
  - [ ] การ์ดยังอยู่ในจอเดียวบน iPhone 16 Pro Max (ย่อช่องได้)
- **นอกขอบเขต:** เปลี่ยนวิธีคำนวณกล้ามหลัก/รอง, เปลี่ยนโปรแกรม
