# Changing a workout date

For a date occupied by the same program ID, restore the date input to the source date and show “This program is already logged on that date.” Keep the row open so the lifter can pick another date. Both saved sessions and the pending History draft must survive reload.

Check the displayed logs and browser storage before detaching a draft or saving. For an available date, move only the selected saved workout and retain its sets and other fields. An open edit of a successfully moved workout still goes through the existing History draft conflict prompt.
