# Spec: แผนวันนี้ (หลายกิจกรรม)

## ข้อมูล
- โปรแกรม: เพิ่ม `slot` ช่วงเวลา `am|noon|pm|night` (ไม่บังคับ) — ชิปเลือกในตัวแก้โปรแกรม (เวท/คาร์ดิโอ) ใต้ "วันในตาราง"
- ลำดับ: slot → (ไม่มี slot) คาร์ดิโอ tag run ก่อน, เวท, คาร์ดิโอที่เหลือ
- สถานะแต่ละแถว: เวท = มี log วันนี้ของโปรแกรมนั้น; คาร์ดิโอ = cxGet(k)

## จอ วันนี้… (มีอย่างน้อย 1 รายการในตาราง)
- การฟื้นตัว (เดิม) → หัว `แผนวันนี้` + ตัวนับ `1/3` (pill)
- แถว: ไอคอน (เวท/คาร์ดิโอ) · ชื่อ · บรรทัดรอง = ไอคอนสถานที่+ชื่อสถานที่ (+ช่วงเวลา) หรือสรุป ✓ · `›`
  - ทำแล้ว: ไอคอนเป็น ✓ เขียว, แถวจาง, สรุป `25 เซ็ต · 4,200 kg` / `10.2 km · 5:40/km` / `บันทึกแล้ว`
  - อย่างถัดไปที่ยังไม่ทำ: ขอบไล่สี + pill "ถัดไป"
- `+ เพิ่มกิจกรรม` (เส้นประ) → แผ่น: เวทเทรนนิ่ง / คาร์ดิโอ → ขั้นไปที่ไหน (กรองตามประเภท)
- `😴 พักวันนี้` (ลิงก์เล็ก ถ้ายังไม่ได้ทำอะไร)
- จอนี้แสดงทุกครั้งที่เปิดแท็บเวทวันนี้ ถ้ายังมีรายการไม่เสร็จ (ยกเว้นกำลังเล่นค้าง); ครบทุกอย่างแล้ว → สรุป "ครบแผนวันนี้ ✓" + เพิ่มกิจกรรม

## แตะแถว
- ตั้ง dayMode=train, สถานที่ = ของโปรแกรม, โปรแกรม = แถวนั้น → หน้าของสถานที่ (การ์ดวันนี้พร้อมปุ่มหลัก)
- แถบเส้นทาง: `แผน 1/3 ⌄ › 🏢 ยิม ⌄ › 📋 Push A ⌄` — แตะ "แผน" กลับจอนี้
- จบ/บันทึก → กลับจอแผนอัตโนมัติ

## วันที่ไม่มีในตาราง
- 3 ตัวเลือกเดิม (เวท / คาร์ดิโอ / พัก)
