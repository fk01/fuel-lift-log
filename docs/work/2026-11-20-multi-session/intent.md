# Intent: หลายกิจกรรมในวันเดียว (เช่น วิ่งเช้า · เวทเย็น · ตีแบดค่ำ)

## ตอนนี้
- ข้อมูลรองรับแล้ว: โปรแกรมหลายตัวตั้ง "วันในตาราง" วันเดียวกันได้, บันทึกแยกกัน (เวท = log, วิ่ง/แบด = tag ของวัน)
- แต่หน้าจอคิดแบบ "วันละ 1 อย่าง": เลือก ออก/พัก → ที่ไหน → โปรแกรมเดียว; ทำเสร็จแล้วการ์ดวันนี้กลายเป็นสรุป ไม่ชวนทำอย่างถัดไป

## หลังเสร็จผู้ใช้จะ
### จอ วันนี้… → "แผนวันนี้" (แทน 3 การ์ดเลือก)
```
การฟื้นตัว (เหมือนเดิม)
แผนวันนี้                         0/3
 ○ 🏃 วิ่ง 10 km        คอนโด     ›
 ○ 🏋 Push A            ยิม       ›
 ○ 🏸 ตีแบด             สนามแบด   ›
 + เพิ่มกิจกรรม (นอกตาราง)
 😴 พักวันนี้
```
- รายการ = ทุกโปรแกรมที่ตารางวันนี้ชี้ (ทุกสถานที่) เรียงตามเวลาที่ตั้ง (ถ้ามี) หรือ คาร์ดิโอเช้า → เวท → คาร์ดิโอเย็น
- แตะแถว → ไปสถานที่นั้น + เลือกโปรแกรมนั้นให้เลย → ปุ่ม ▶ เริ่ม / บันทึก (ข้ามขั้น "ไปที่ไหน")
- ทำเสร็จ → กลับมาที่แผนวันนี้ แถวนั้นเป็น ✓ พร้อมสรุปสั้น (`✓ Push A · 25 เซ็ต · 4,200 kg`, `✓ วิ่ง 10.2 km · 5:40/km`)
- `+ เพิ่มกิจกรรม` = เวท / คาร์ดิโอ นอกตาราง (เหมือนตัวเลือกเดิม)
- วันที่ไม่มีอะไรในตาราง: แสดง 3 ตัวเลือกเดิม (เวท / คาร์ดิโอ / พัก)

### ระหว่างวัน
- แถบเส้นทาง: `วันนี้ 1/3 › 🏢 ยิม › 📋 Push A` — แตะ "วันนี้" กลับไปแผน
- เปิดแอปอีกรอบหลังทำอย่างแรก → เห็นแผนวันนี้ (ไม่ใช่หน้าสรุปของอย่างเดียว)

### ตั้งตาราง
- โปรแกรมเวท/คาร์ดิโอ: นอกจาก "วันในตาราง" เพิ่ม "ช่วงเวลา" (เช้า / กลางวัน / เย็น / ค่ำ) ไว้เรียงลำดับ — ไม่บังคับ

### อาหาร
- มื้อเสริมหลังวิ่ง / วันแบด ยังเพิ่มเองเหมือนเดิม (ทำได้ทั้งคู่ในวันเดียว)

### สถิติ / การฟื้นตัว
- นับทุกกิจกรรมของวันรวมกัน (เป็นแบบนี้อยู่แล้ว)

## เกณฑ์สำเร็จ
- [ ] ตั้งตารางวันเดียวมี วิ่ง + Push A + ตีแบด แล้วจอวันนี้แสดง 3 แถว
- [ ] ทำเสร็จทีละอย่าง กลับมาเห็น ✓ และอย่างถัดไปพร้อมกด (2 แตะต่อกิจกรรม)
- [ ] บันทึกทั้ง 3 อย่างของวันเดียวกันได้ครบ ไม่ทับกัน

## นอกขอบเขต
- แจ้งเตือนตามเวลาของแต่ละกิจกรรม
