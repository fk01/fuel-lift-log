# Spec: หน้าเวทตาม story

## 1. จอเลือกสถานที่ (จอแรกของวัน)
- แสดงเมื่อ: วันนี้, ยังไม่เลือกที่วันนี้, ไม่ได้เล่นค้าง, ยังไม่ได้บันทึกอะไรวันนี้ (แสดงแม้วันพัก — ผู้ใช้อาจออกนอกตาราง; วันพักแสดง "วันพัก · ออกได้ถ้าอยากออก")
- ซ่อนแถบสัปดาห์ / เลเวล / ทุกอย่างอื่น; หัว "วันนี้ออกที่ไหน?" + วันที่
- การ์ดสถานที่ (สูง ~88px): ไอคอนใหญ่ · ชื่อ · บรรทัดรอง = โปรแกรมวันนี้ของที่นั้น (`▶ Push A · 7 ท่า` / `🏸 ตีแบด`) หรือ `N โปรแกรม` ถ้าไม่มี; ป้าย "ล่าสุด"; ••• แก้ไข
- ลำดับ: ที่ที่มีโปรแกรมวันนี้ก่อน → ที่ล่าสุด
- ปุ่มเส้นประ "+ เพิ่มสถานที่"

## 2. หน้าของสถานที่
- หัวจอ: `Workout` → ใต้หัว แถว `🏠 คอนโด` (ตัวใหญ่ 20px) + ปุ่ม `เปลี่ยน` ทางขวา — **ที่เดียวที่แสดงสถานที่**
- แถบสัปดาห์ (เหมือนเดิม)
- การ์ดวันนี้:
  - มีโปรแกรมของวันนี้ที่นี่ → ชื่อ + สรุป + **ปุ่มหลักปุ่มเดียว**
  - ไม่มี → หัว "เลือกโปรแกรม" + "ไม่มีโปรแกรมในตารางวันนี้ที่นี่" + ลิงก์ "ดูโปรแกรม ↓" (ไม่โชว์ชื่อแผนของที่อื่น ไม่มีชิป)
  - ทำแล้ว / กำลังเล่น → เหมือนเดิม
- "โปรแกรม" (หัวข้อ 20px) → การ์ดเวท → การ์ดคาร์ดิโอ (ไม่มีหัวข้อย่อย "เวท"; คาร์ดิโอคั่นด้วยหัวข้อย่อยเมื่อมีทั้งคู่) → "+ เพิ่มโปรแกรม" → "ออกแบบอิสระ"
- การ์ดเลเวล ย้ายไปล่างสุด
- ลบชิปสถานที่ในการ์ดวันนี้และใต้หัวข้อโปรแกรม

## 3. คำแปล
- เพิ่มคีย์แยก `N โปรแกรม` (นับ) ไม่ทับคำว่า "โปรแกรม" (หัวข้อ) → หัวข้อ EN = "Programs"
