# Intent: story หน้าเวท — "มาถึงต้องเลือกสถานที่ก่อน"

## ปัญหาจากภาพบนเครื่อง (device-before.png)
- ไม่รู้ว่าต้องเลือกสถานที่ก่อน: ชิป `🏢 Gym ⌄` เล็ก อยู่มุมการ์ด และซ้ำอีกอันใต้ "programs"
- การ์ดวันนี้ขัดกันเอง: หัวข้อ "Badminton" แต่ปุ่มเป็น Push A / Pull A / … / Run (ไม่มีปุ่มหลัก)
- หัวข้อ "programs" ตัวเล็ก (บั๊กคำแปล) + "Weights" ซ้ำชั้น
- ลำดับชั้นข้อมูลไม่ชัด: วันนี้ → เลเวล → โปรแกรม ทุกอย่างหนักเท่ากัน

## Story
**ฉัน (ผู้ใช้)** เปิดแท็บเวทตอนจะออกกำลังกาย
1. **ที่ไหน** — จอแรกถาม "วันนี้ออกที่ไหน?" เต็มจอ การ์ดใหญ่ต่อสถานที่ (ไอคอน · ชื่อ · โปรแกรมวันนี้ของที่นั้น) → แตะ 1 ครั้ง
   - ถ้าเลือกไปแล้ววันนี้ ข้ามจอนี้ แต่หัวจอบอกชัด `🏠 คอนโด · เปลี่ยน`
2. **ทำอะไร** — หน้าของสถานที่: หัวจอใหญ่ = ชื่อสถานที่; การ์ดวันนี้ = โปรแกรมตามตารางของที่นี้ + ปุ่มหลักปุ่มเดียว (`▶ เริ่ม Push A` / `🏸 บันทึกตีแบด`)
   - ที่นี้ไม่มีโปรแกรมของวันนี้ → การ์ดวันนี้เขียน "เลือกโปรแกรม" แล้วให้เลือกจากรายการด้านล่าง (ไม่โชว์ชื่อแผนของที่อื่น)
3. **เริ่ม** — กดปุ่มหลัก → เข้าโหมดเล่น (เหมือนเดิม, มีป้ายสถานที่)
4. **จบ** — บันทึก → การ์ดวันนี้เป็นสรุป ✓

## หลังแก้ผู้ใช้จะ
- เห็นทันทีว่าขั้นแรกคือเลือกสถานที่ และตอนนี้อยู่ที่ไหน (มีที่เดียวบนจอ)
- การ์ดวันนี้มีปุ่มหลักปุ่มเดียวเสมอ หรือบอกให้เลือกโปรแกรม
- รายการโปรแกรมของสถานที่อยู่ใต้การ์ดวันนี้ ไม่มีชิปสถานที่ซ้ำ
- การ์ดเลเวลย้ายไปใต้รายการ (ไม่แทรกระหว่าง "ทำอะไร")

## เกณฑ์สำเร็จ
- [ ] จอแรกของวัน = เลือกสถานที่ (ทุกวันที่มีโปรแกรมในตาราง และยังไม่ได้ทำ)
- [ ] สถานที่ปัจจุบันแสดงที่เดียว ที่หัวจอ
