# Intent: ซ่อนรูปท่า (GIF) — เปิดดูผ่านไอคอน How to

- **ปัญหา:** รูป GIF ท่าออกกำลังกายขึ้นอยู่หลายที่ (แผ่นโปรแกรม, การ์ดท่าตอนเล่น, คลังท่า, แผ่นกล้ามเนื้อ, 1RM เด่น) ภาพขาวสว่างตัดกับพื้นดำ ขยับตลอด รก และกินที่
- **ทำไม:** อยากให้หน้าดูสะอาด อ่านง่าย รูปท่าดูเฉพาะตอนอยากรู้วิธีเล่น
- **หลังเสร็จผู้ใช้จะ:** เห็นรายการท่าแบบเรียบ (ไอคอน/หุ่นกล้ามเล็ก + ชื่อ) และแตะไอคอน **▶ How to** เพื่อเปิดแผ่นวิธีเล่น (GIF + ขั้นตอน)
- **เกณฑ์สำเร็จ:**
  - [ ] ไม่มี GIF แสดงในรายการ/การ์ดใดเลยโดยตรง
  - [ ] ท่าที่มีวิธีเล่น มีไอคอน ▶ (ขนาดกดง่าย ≥ 44 pt) ทุกที่ที่เคยมีรูป
  - [ ] แตะไอคอน → แผ่นเลื่อนขึ้น: ชื่อท่า, GIF, ขั้นตอน, (ลิงก์ YouTube ถ้ามี)
  - [ ] ช่องรูปเดิมแทนด้วยหุ่นกล้ามเล็ก (มัดที่โดน) หรือไอคอนอุปกรณ์
  - [ ] กล่อง "How to" แบบพับในการ์ดท่าตอนเล่น/คลังท่า เปลี่ยนเป็นไอคอนเดียวกัน
- **นอกขอบเขต:** เปลี่ยน/เพิ่มชุดรูปท่า
