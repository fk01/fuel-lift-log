# Intent: แตะมัดกล้าม → แผ่นเลื่อนขึ้น

- **ปัญหา:** แตะช่องมัดในการฟื้นตัวแล้วกล่องรายละเอียดเด้งแทรกระหว่างแถบ "ควรเล่น" กับตาราง → ตารางถูกดันลง ช่องที่แตะเลื่อนหนี, หุ่นเล็กมองไม่ออกว่ามัดอยู่ตรงไหน, ข้อมูลน้อย (แค่ชื่อท่า)
- **ทำไม:** อยากรู้ว่ามัดนี้โดนจากท่าไหน หนักแค่ไหน และถ้ายังไม่เคยเล่น ควรเล่นท่าอะไร
- **ทางที่เลือก:** แผ่นเลื่อนขึ้นจากล่าง (แบบแผ่นโปรแกรม) — ตารางอยู่นิ่ง
- **เกณฑ์สำเร็จ:**
  - [ ] แตะช่องมัด → แผ่นเลื่อนขึ้น, ตาราง/หน้าไม่ขยับ, เอากล่องรายละเอียดเดิมออก
  - [ ] ในแผ่น: ชื่อมัด + สถานะ (สี) + วันที่, หุ่นใหญ่ไฮไลต์เฉพาะมัดนั้น
  - [ ] "ท่าที่เล่นล่าสุด": รูป GIF + ชื่อท่า + เซ็ต × น้ำหนักครั้งล่าสุด + วันที่
  - [ ] "ท่าที่ช่วยมัดนี้ในโปรแกรม": ท่าในโปรแกรมที่มัดนี้เป็นกล้ามหลัก/รอง + โปรแกรมไหน (มีประโยชน์ที่สุดตอน "ยังไม่เคยเล่น"/"ละเลย")
  - [ ] ปิดได้ด้วยแตะพื้นหลัง / ลากลง
- **นอกขอบเขต:** เปลี่ยนสถานะ/สี, เพิ่มท่าเข้าโปรแกรมจากแผ่นนี้ (อาจทำงานถัดไป)
