# Spec: ชิปโปรแกรมในแถบเส้นทาง (intent = ข้อความผู้ใช้ + device-request.jpg)

## แถบ
`วันนี้ › 💪 ออก ⌄ › 🏢 ยิม ⌄ › 📋 Push A ⌄`
- ค่าเริ่ม: โปรแกรมตามตารางวันนี้ของสถานที่นี้ (ถ้ามี) — ไม่มี → ชิป `เลือกโปรแกรม ⌄` ขอบสว่าง (cur)
- แตะชิป → แผ่น "เลือกโปรแกรม · 🏢 ยิม": กลุ่ม **เวท** (ชื่อ · จำนวนท่า · กลุ่มกล้าม · ป้าย "ตามตาราง") และ **คาร์ดิโอ** (ไอคอน · ชื่อ) + `ออกแบบอิสระ` ท้ายสุด; รายการที่เลือกอยู่มี ✓
- เลือก → ชิปเปลี่ยน, การ์ดวันนี้อัปเดต (จำไว้ทั้งวัน: `locDay.prog`)
- ระหว่างเล่น: `▶ Push A` ล็อก · ทำแล้ว: ไม่แสดงชิปโปรแกรม

## การ์ดวันนี้
- มีโปรแกรมที่เลือก: ชื่อ + สรุป + คำเตือนการฟื้นตัว + ปุ่มหลัก `▶ เริ่ม Push A` / `🏸 บันทึกตีแบด` + `พักแทน`
- ยังไม่เลือก: "เลือกโปรแกรม" + ปุ่มหลัก `เลือกโปรแกรม` (เปิดแผ่นเดียวกัน) — เอา "ดูโปรแกรม ↓" ออก
