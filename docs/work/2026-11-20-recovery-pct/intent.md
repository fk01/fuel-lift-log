# Intent: % การฟื้นตัวของกล้ามแต่ละมัด

## ปัญหา
- การ์ดการฟื้นตัวบอกแค่สถานะสี (เพิ่งเล่น / กำลังฟื้น / พร้อม / ละเลย) — ไม่รู้ว่าฟื้นไปแค่ไหน ใกล้พร้อมหรือยัง
- นับเป็นวัน ไม่สนว่าเล่นหนักแค่ไหน และกล้ามใหญ่/เล็กฟื้นไม่เท่ากัน

## หลังเสร็จผู้ใช้จะ
- เห็น **% ฟื้นตัว** ทุกมัด (0–100%) พร้อมแถบสีในการ์ดการฟื้นตัว และบนรูปกล้าม (สีอ่อน→เข้มตาม %)
- ในแผ่นกล้ามเนื้อเห็น "ฟื้น 65% · พร้อมเต็มที่ประมาณ พรุ่งนี้ 18:00"
- การ์ดวันนี้ (หน้าเวท) บอกถ้าโปรแกรมวันนี้โดนมัดที่ยังฟื้นไม่ถึง 70% เช่น "อก 55% ยังไม่ฟื้นเต็ม" (แค่บอก ไม่บล็อก)

## วิธีคิด %
- เวลาฟื้นเต็มตามขนาดกล้าม: ใหญ่ (อก, หลังกว้าง, ต้นขาหน้า, ต้นขาหลัง, ก้น) 72 ชม. · กลาง (ไหล่, หลังไหล่, บ่า, หน้าแขน, หลังแขน, ขาใน, ขานอก) 48 ชม. · เล็ก (น่อง, หน้าท้อง, เอว, ปลายแขน) 36 ชม.
- ปรับตามความหนัก: จำนวนเซ็ตที่โดนมัดนั้นในครั้งล่าสุด (หลัก = 1, รอง = 0.5) — ≤ 4 เซ็ต ×0.75 · 5–10 ×1 · > 10 ×1.25
- เวลาเริ่มนับ = ตอนกดจบและบันทึก (เก็บเวลาใน log ใหม่); log เก่าไม่มีเวลา → ใช้ 20:00 ของวันนั้น
- % = ชั่วโมงที่ผ่านไป ÷ เวลาฟื้นเต็ม (สูงสุด 100); "ละเลย" (> 7 วัน) ยังแสดงเหมือนเดิม

## เกณฑ์สำเร็จ
- [ ] การ์ดการฟื้นตัวแสดง % ครบ 16 มัด, ยังพอดีจอ
- [ ] แผ่นกล้ามเนื้อบอก % และเวลาที่จะพร้อม
- [ ] การ์ดวันนี้เตือนมัดที่ < 70% ในโปรแกรมวันนี้
- [ ] log ใหม่เก็บเวลาจบ

## นอกขอบเขต
- ปรับตามการนอน / อาหาร / ความรู้สึกล้า
