# Spec: % การฟื้นตัว

## ข้อมูล / การคำนวณ (`recPct()` ใน stats-extra.js)
- log ใหม่: `at` = เวลา (ms) ตอนกดจบและบันทึก; log เก่า → `date` 20:00 เวลาเครื่อง
- ต่อมัด m: ครั้งล่าสุดที่โดน (หลักหรือรอง) → `t0`, เซ็ต = Σ(หลัก 1 + รอง 0.5 ต่อเซ็ต) ในครั้งนั้น
- ชั่วโมงฟื้นเต็ม `H = BASE[m] × k` ; BASE ใหญ่ 72 / กลาง 48 / เล็ก 36 ; k = 0.75 (≤4) · 1 (5–10) · 1.25 (>10)
- `% = clamp(0,100, (now − t0)/H)` ; `readyAt = t0 + H`
- สถานะสีใหม่จาก %: 0 ยังไม่เคย · < 40% แดง · 40–99% ส้ม · 100% เขียว · > 7 วัน ม่วง (ละเลย)
- อัปเดตทุก 5 นาทีขณะเปิดหน้า (ไม่ต้องรีเฟรช)

## การ์ดการฟื้นตัว (สถิติ › การฝึก)
- รูปกล้าม: สีตามสถานะใหม่
- ตาราง 16 ช่อง (4 คอลัมน์ เท่าเดิม): ชื่อ · ตัวเลข `65%` (mono) · แถบ 3px สีตามสถานะ ; ยังไม่เคย = "–" ; ละเลย = "12 วัน"
- แถว "ควรเล่น": มัดที่ละเลย/ยังไม่เคย (เหมือนเดิม)
- legend: แดง < 40% · ส้ม กำลังฟื้น · เขียว พร้อม · ม่วง ละเลย · เทา ยังไม่เคย

## แผ่นกล้ามเนื้อ
- บรรทัดสถานะ: `ฟื้น 65% · พร้อมเต็มที่ พรุ่งนี้ 18:00` / `พร้อมแล้ว · เล่นล่าสุด 3 วันก่อน`
- แถบ % กว้างเต็ม ใต้บรรทัดสถานะ

## การ์ดวันนี้ (หน้าเวท)
- เมื่อปุ่มหลักเป็น `▶ เริ่ม <โปรแกรม>`: ถ้ามีมัดหลักของโปรแกรมที่ < 70% → บรรทัดเตือนสีส้มใต้สรุป `⚠ อก 55% · ไหล่ 62% ยังไม่ฟื้นเต็ม` (สูงสุด 3 มัด)
