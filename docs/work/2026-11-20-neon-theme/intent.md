# Intent: ธีมใหม่ "นีออน" ตามภาพอ้างอิง (ref-*.jpg)

## ภาพอ้างอิงบอกอะไร
- พื้นน้ำเงินเทาเข้ม (#1b2230 ประมาณ) + ลายวงจรจาง ๆ
- สีหลักไล่ **ฟ้า (cyan) → เขียว (neon green)** มีแสงเรือง (glow) รอบขอบ/ตัวเลข
- การ์ดขอบเรืองแสงไล่สี, มุมตัด/บากแบบ HUD
- ตัวเลขแบบดิจิทัล (เวลา, kcal, kg)
- **วงแหวน** ใหญ่: แคล/โปรตีนหน้าอาหาร, ตัวนับพักระหว่างเซ็ต
- รูปกล้ามเรืองแสงตามสถานะ
- ปุ่มติ๊กเซ็ตเป็นสี่เหลี่ยมเขียวเรือง

## หลังเสร็จ
- ทั้งแอปใช้ชุดสีใหม่ (ฟ้า-เขียวนีออน บนน้ำเงินเข้ม) แทนครีมบนดำ — เปลี่ยนที่ token สี จุดเดียว
- **อาหาร:** วงแหวนคู่ kcal (ฟ้า) + โปรตีน (เขียว) แทนแถบ, รายการมื้อเป็นการ์ดขอบเรือง + ช่องติ๊กใหญ่
- **ระหว่างเล่น:** ตัวนับพักเป็นวงแหวนใหญ่กลางจอ, เวลารวมตัวเลขดิจิทัล, ช่อง kg/ครั้งกรอบ HUD, ติ๊กเป็นสี่เหลี่ยมเขียวเรือง
- **ไปที่ไหน / ออกหรือพัก:** การ์ดใหญ่ขอบเรืองไล่สี มุมบาก + ไอคอนหมุดนีออน
- **การฟื้นตัว:** รูปกล้ามเรืองแสง (เขียว = พร้อม, ฟ้า = กำลังฟื้น, แดงส้ม = ต่ำ), พื้นหลังเส้นตาราง
- **กราฟ:** เส้นไล่สีฟ้า-เขียว + พื้นที่ใต้กราฟเรือง

## ข้อจำกัด / เรื่องที่ต้องรู้
- ภาพอ้างอิงเป็นภาพ AI — จะใช้ "สไตล์" (สี แสง กรอบ วงแหวน ฟอนต์) ไม่ใช่ลอกทุกพิกเซล; ข้อความ/ข้อมูลยังเป็นของจริงในแอป
- ฟอนต์ดิจิทัลใช้กับตัวเลขเท่านั้น; ภาษาไทยยังใช้ IBM Plex Sans Thai เพื่ออ่านง่าย
- แสงเรืองใช้เท่าที่จำเป็น (ปุ่มหลัก/ตัวเลขสำคัญ) เพื่อไม่ให้อ่านยากกลางแดด/ในยิม และไม่เปลืองแบต
- เลย์เอาต์และ flow เดิมไม่เปลี่ยน (แถบเส้นทาง, การ์ดวันนี้ ฯลฯ)

## แบ่งทำ (แนะนำ)
1. ชุดสี + การ์ด/ปุ่ม/ชิป + ฟอนต์ตัวเลข (ทั้งแอปเปลี่ยนหน้าตาทันที)
2. วงแหวนอาหาร + วงแหวนพักระหว่างเซ็ต
3. รูปกล้ามเรืองแสง + กราฟไล่สี + การ์ดสถานที่แบบ HUD
