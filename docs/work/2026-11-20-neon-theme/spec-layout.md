# Spec: เลย์เอาต์ตามภาพอ้างอิง (รอบ 2)

## 🍽 อาหาร (ref-food.jpg → "Daily Goals")
- บนสุด: **วงแหวนคู่ใหญ่** (กว้าง ~70% จอ) วงนอก kcal ฟ้า, วงใน โปรตีน เขียว; กลางวง: `1,690 kcal` (ใหญ่) / `124 g โปรตีน`; ใต้วง: "ขาด 36 g · ถัดไป 15:00 บ่าย"
- แถบสัปดาห์ย่อเป็นแถวเล็กเหนือวง
- รายการมื้อ: การ์ดแถวเดียวสูง 64px — ชื่อมื้อ (ใหญ่) · เวลา/kcal (เล็ก) · ช่องติ๊กใหญ่ขวา 44px; แตะการ์ด = กางรายละเอียด
- `+ บันทึกอาหาร` เป็นปุ่มลอยกลม (FAB) มุมขวาล่างเหนือแถบเมนู
- ชิปประเภทวัน (วิ่ง/แบด/เวทค่ำ) ย้ายเข้าเมนู ⚙ มุมขวาบน

## 🏋 ระหว่างเล่น (ref-workout.jpg)
- หัว: `Workout` + เวลาเล่นตัวเลขดิจิทัลใหญ่ขวา
- ท่าทีละท่า (ท่าปัจจุบันเต็มจอ, เลื่อนซ้าย/ขวาหรือแตะชื่อท่าเพื่อเปลี่ยน): ชื่อท่า · แถว `Set 1 [20 kg] [5 reps] [✓]` ตัวใหญ่
- **วงแหวนพักใหญ่กลางจอ** ใต้รายการเซ็ต: นับถอยหลัง 01:30 · "พัก" · แตะ = ข้าม / +15 วิ
- ล่าง: ยกเลิก · จบและบันทึก (เหมือนเดิม)

## 🏋 ออกหรือพัก / ไปที่ไหน (ref-where.jpg)
- หัวข้อในกรอบ HUD มุมบาก
- การ์ดใหญ่เต็มกว้าง สูง ~160px: ไอคอนใหญ่ (หมุด/ดัมเบล/ไม้แบด) · ชื่อ · บรรทัดรอง; การ์ดสลับซ้าย-ขวาไอคอน, ขอบไล่สีต่างกันแต่ละใบ
- ช่องค้นหาสถานที่ (แสดงเมื่อมี > 4 ที่)

## 📈 สถิติ › การฝึก (ref-recovery.jpg)
- หัวข้อ `Recovery` + รูปกล้าม **ใหญ่เต็มกว้าง** (หน้า-หลัง) เรืองแสงตามสถานะ บนพื้นเส้นตาราง; แตะกล้ามบนรูป = เปิดแผ่นกล้ามนั้น
- ตาราง % 16 มัดย่อเป็น 2 แถวเลื่อนแนวนอน (ชิป `อก 36%`) ใต้รูป
- การ์ด **Workout volume** รวม: กราฟเส้นไล่สี (วอลุ่ม) + แถบเซ็ตต่อกล้าม + แท่งรายวัน ในการ์ดเดียว
