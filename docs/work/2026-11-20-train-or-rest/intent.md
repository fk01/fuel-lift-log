# Intent: "วันนี้ออกหรือพัก → ออกที่ไหน"

## ปัญหา (device-before.png)
- หน้าเวทเปิดมาเป็นหน้าของสถานที่ (Gym) + การ์ด "วันพัก" + รายการโปรแกรม — ข้อมูลครบแต่ไม่ได้ถามสิ่งที่ผู้ใช้คิดจริง
- ผู้ใช้คิดเป็นลำดับ: **วันนี้จะออกกำลังกายหรือพัก?** → ถ้าออก **ไปที่ไหน?** → **ทำอะไร**
- ตอนนี้: วันพักไม่ถามอะไรเลย (ต้องหา "Train anyway"), วันมีแผนถามสถานที่ทันที (ข้ามคำถามแรก)

## Story
1. **ออกหรือพัก** — จอแรกของวัน (ยังไม่ได้บันทึก/ยังไม่ได้ตัดสินใจ): หัว "วันนี้…" + 2 ตัวเลือกใหญ่
   - `💪 ออกกำลังกาย` — บรรทัดรองบอกแผนตามตาราง (เช่น "ตามตาราง: Push A") ; วันพักบอก "นอกตาราง"
   - `😴 พัก` — บรรทัดรองบอกการฟื้นตัว (เช่น "อก 27% · ไหล่ 33% ยังฟื้นไม่เต็ม")
   - ตัวเลือกที่ตรงกับตารางมีป้าย "แนะนำ"
2. **ไปที่ไหน** (เมื่อเลือกออก) — การ์ดสถานที่แบบเดิม (โปรแกรมวันนี้ของแต่ละที่) + ปุ่ม `‹ กลับ`
3. **ทำอะไร** — หน้าของสถานที่เหมือนตอนนี้ (การ์ดวันนี้ปุ่มหลักเดียว)
4. **เลือกพัก** — การ์ด "😴 พักวันนี้" + สรุปการฟื้นตัว + ลิงก์เล็ก "เปลี่ยนใจ ออกกำลังกาย"; ไม่แสดงรายการโปรแกรม (ลดสิ่งรบกวน)
- จำการตัดสินใจทั้งวัน; บันทึกอะไรไปแล้ว / กำลังเล่น → ข้ามไปหน้าของสถานที่
- หัวหน้าของสถานที่ยังมี `เปลี่ยน` (กลับไปขั้น 2) และเพิ่มทางกลับขั้น 1 ("พักแทน")

## เกณฑ์สำเร็จ
- [ ] เปิดแท็บเวทครั้งแรกของวัน เห็นคำถาม ออก/พัก ก่อนทุกอย่าง
- [ ] วันมีแผน: ออก → ที่ไหน → เริ่ม = 3 แตะ
- [ ] วันพัก: กด "พัก" 1 แตะ จบ
- [ ] ทุกขั้นย้อนกลับได้
