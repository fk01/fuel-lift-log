# Spec: ออกหรือพัก → ที่ไหน → ทำอะไร

## สถานะต่อวัน (`dayMode` ใน localStorage `daymode` = {date, mode: "train"|"rest"})
- ยังไม่มี mode วันนี้ + ยังไม่ได้บันทึก/เล่นค้าง → ขั้น 1
- mode=train + ยังไม่เลือกที่ (locDay) → ขั้น 2
- mode=train + เลือกที่แล้ว / มีบันทึกวันนี้ / เล่นค้าง → ขั้น 3 (หน้าของสถานที่)
- mode=rest → ขั้น 4
- ย้อนดูวันอื่น (DAY≠TODAY) → ขั้น 3 เสมอ

## ขั้น 1 · "วันนี้…" (เต็มจอ ซ่อนหัว/แถบสัปดาห์เหมือนหน้าเลือกสถานที่)
- หัว `วันนี้…` + วันที่
- การ์ดใหญ่ 2 ใบ (สูง ~140px, ไอคอน 40px):
  - `💪 ออกกำลังกาย` · รอง: `ตามตาราง: Push A` / `🏸 ตีแบด` / `นอกตาราง — เลือกเองได้`
  - `😴 พัก` · รอง: 2–3 มัดที่ฟื้นน้อยสุด `อก 27% · ไหล่ 33% ยังฟื้นไม่เต็ม` หรือ `กล้ามฟื้นครบแล้ว`
  - ป้าย `แนะนำ` บนการ์ดที่ตรงตาราง (มีแผน → ออก, ไม่มี → พัก) + ขอบสว่าง
- แตะ = เลือก (ไม่มีปุ่มยืนยัน)

## ขั้น 2 · "ไปที่ไหน?" — หน้าเลือกสถานที่เดิม + `‹ กลับ` (กลับขั้น 1)

## ขั้น 3 · หน้าของสถานที่ — เหมือนเดิม; แถวหัว `🏢 ยิม` มี `เปลี่ยน` (ขั้น 2); การ์ดวันนี้ทุกแบบมีลิงก์เล็ก `พักแทน` เมื่อยังไม่ได้บันทึก
- การ์ดวันนี้วันพัก+เลือกออกเอง: หัว "เลือกโปรแกรม" (ไม่ใช่ "วันพัก")

## ขั้น 4 · พัก
- การ์ด `😴 พักวันนี้` + ลิสต์การฟื้นตัวย่อ (3 มัดต่ำสุดพร้อมแถบ %) + ลิงก์ `เปลี่ยนใจ ออกกำลังกาย` (→ ขั้น 2)
- ซ่อนรายการโปรแกรม / ออกแบบอิสระ / การ์ดเลเวล ยังแสดง
