# Intent: ใช้สไตล์จอ "วันนี้…" ให้ครบทุกหน้า (ref-today.png)

## หลักของสไตล์ (ดึงจากจอที่ผู้ใช้ชอบ)
1. **หัวข้อหน้า:** ตัวหนาเรียบ + เส้นไล่สีฟ้า-เขียวสั้นเรืองใต้หัวข้อ; หัวข้อส่วนย่อยตัวหนาขนาดกลาง ไม่มีกรอบ
2. **แถวการ์ดแนวนอน:** ไอคอนเส้น (SVG) เรือง ซ้าย · ชื่อ (หนา) + บรรทัดรอง (เทา) · `›` ขวา
3. **ไอคอนเส้นแทนอีโมจิ** ในส่วนที่แอปกำหนด (อาหาร/มื้อ, โปรแกรม, คาร์ดิโอ, เมนู) — อีโมจิที่ผู้ใช้ตั้งเอง (ไอคอนสถานที่) คงไว้
4. **ป้ายสถานะ = pill โปร่งแสง** (เขียว = แนะนำ/ทำแล้ว, ส้ม = เลยเวลา/ยังไม่ฟื้น, ฟ้า = ตอนนี้)
5. **แถบ % เล็ก** ใต้ข้อความแทนตัวเลขลอย ๆ
6. **การ์ดหลักที่ถูกเลือก/แนะนำ:** ขอบไล่สีเต็ม + มุมบาก; การ์ดอื่นขอบบาง
7. **ตัวเลขสำคัญ:** ฟอนต์ดิจิทัลสีฟ้า

## หน้าที่จะปรับ
- **อาหาร:** หัวข้อ + วงแหวน; มื้อเป็นแถวแนวนอน (ไอคอนมื้อ · ชื่อ+เวลา/kcal · ช่องติ๊กขวา), ป้าย "ถัดไป"/"เลยเวลา" เป็น pill, รายการบันทึกเองเป็นแถวย่อย
- **เวท · หน้าของสถานที่:** การ์ดโปรแกรมจากตาราง 2 คอลัมน์ → แถวแนวนอน (ไอคอนดัมเบล/คาร์ดิโอ · ชื่อ + "7 ท่า · อก ไหล่" · ล่าสุด pill · ›); การ์ดวันนี้ใช้หัวแบบเดียวกัน
- **ไปที่ไหน:** การ์ดสถานที่แบบเดียวกับออก/พัก (ไอคอน · ชื่อ · โปรแกรมวันนี้ · ›), "ล่าสุด" เป็น pill
- **ระหว่างเล่น:** หัวท่าเป็นแถว (ไอคอน · ชื่อท่า · 1/7), แถวเซ็ตคงเดิม
- **สถิติ:** หัวข้อส่วนมีเส้นเรือง, การ์ดสรุปเป็นแถว (ไอคอน · ค่า · ป้าย), กล่อง % กล้ามเป็นแถวพร้อมแถบ
- **เพิ่มเติม:** แถวเมนูไอคอนเรือง + `›`, กลุ่มมีหัวข้อแบบเดียวกัน
- **แผ่นล่าง (sheet):** หัวแผ่นแบบเดียวกัน, รายการเป็นแถวแนวนอน
