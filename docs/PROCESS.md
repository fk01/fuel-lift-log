# ขั้นตอนการทำงาน (AI-native SDLC)

ทุกงาน (ฟีเจอร์ / แก้บั๊ก / ปรับ UI) เดินตามวงนี้ และทุกขั้น commit ลง git

```
วางแผน ──intent.md──▶ ออกแบบ ──spec.md──▶ เขียนโค้ด ──plan.md──▶ เทส
   ▲                                                              │
   │                                                          โค้ด+เทส
ดูแลระบบ ◀──────PR────── deploy ◀────────────────────────────────┘
```

| ขั้น | ใครทำ | ผลลัพธ์ (commit) | จบเมื่อ |
|---|---|---|---|
| 1. วางแผน | ผู้ใช้บอกความต้องการ, Claude สรุป | `docs/work/<งาน>/intent.md` — อยากได้อะไร ทำไม เกณฑ์สำเร็จ | ผู้ใช้ตอบ **OK** |
| 2. ออกแบบ | Claude | `spec.md` — หน้าจอ/ข้อมูล/พฤติกรรม + ภาพ mockup ถ้าเป็น UI | ผู้ใช้ตอบ **OK** |
| 3. เขียนโค้ด | Claude | `plan.md` (ขั้นตอน + ไฟล์ที่แตะ) แล้วโค้ดตาม plan | ทุกข้อใน plan ติ๊กครบ |
| 4. เทส | Claude | เทสอัตโนมัติใน `tests/` + ภาพหน้าจอ | `npm test` ผ่าน, ส่งภาพให้ผู้ใช้ |
| 5. deploy | Claude เปิด PR → ผู้ใช้สั่ง **M** | PR เข้า `main` → Cloudflare deploy อัตโนมัติ | PR merged |
| 6. ดูแลระบบ | ผู้ใช้ลองบนเครื่องจริง | ปัญหาที่เจอ → กลับไปขั้น 1 เป็นงานใหม่ | — |

## คำสั่งสั้น
- **OK** = ผ่านขั้นนี้ ไปขั้นถัดไป
- **M** = merge PR เข้า main (deploy)
- **ข้าม** = งานเล็กมาก (แก้คำ/สี/ระยะ) ข้ามขั้น 1–2 ได้ แต่ยังต้องมี plan.md สั้น ๆ และเทส

## โครงไฟล์
```
docs/work/
  2026-11-20-<ชื่องาน>/
    intent.md
    spec.md
    plan.md
tests/
  smoke.cjs        เปิดทุกแท็บ/หน้าต่างหลัก ต้องไม่มี error
```
