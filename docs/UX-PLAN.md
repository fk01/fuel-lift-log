# แผนปรับ UX — Fuel & Lift

อัปเดต: 19 พ.ย. 2026 · อ้างอิงจากการรีวิวหน้าจอทั้ง 4 แท็บบนขนาด iPhone 16 Pro Max

## แนวคิดหลัก

แอปนี้ใช้ **ทุกวัน** ทั้งในยิมและระหว่างวัน คำถามที่ผู้ใช้มีทุกครั้งที่เปิดแอปคือ

> **"วันนี้ต้องทำอะไร และทำไปถึงไหนแล้ว"**

ทุกหน้าต้องตอบคำถามนี้ได้ในแวบเดียว หลักที่ใช้ตัดสินใจทุกข้อด้านล่าง:

1. **วันนี้มาก่อน** — สิ่งที่ต้องทำวันนี้อยู่บนสุดเสมอ ประวัติและสถิติอยู่ทีหลัง
2. **หนึ่งหน้าจอ หนึ่งงาน** — หน้าอาหาร = กินวันนี้, หน้าเวท = ออกวันนี้, หน้าสถิติ = ย้อนดู
3. **ปุ่มหลักปุ่มเดียว** — แต่ละหน้ามีปุ่มเด่นที่สุดแค่ปุ่มเดียว
4. **ทางไปที่เดียว** — ฟีเจอร์หนึ่งเข้าได้จากที่เดียวที่ชัดเจน ไม่ซ้ำหลายทาง
5. **ใช้งานมือเดียวในยิม** — ปุ่มใหญ่ กดง่าย ตัวหนังสืออ่านออกในที่แสงจ้า

## โครงหน้าจอเป้าหมาย

```
แถบเมนูล่าง (4 แท็บ)
├── 🍽️ อาหาร    วันนี้: แคล/โปรตีน → มื้อถัดไป → รายการมื้อ (ที่กินแล้วย่อ)
├── 🏋️ เวท      การ์ด "วันนี้" (ปุ่มเริ่ม) → โปรแกรมอื่น → คาร์ดิโอ
├── 📈 สถิติ    [การฝึก | ร่างกาย]
│                 การฝึก: วอลุ่ม, การฟื้นตัว, เซ็ตต่อกล้าม, 1RM, ความก้าวหน้า
│                 ร่างกาย: น้ำหนัก/ไขมัน, โภชนาการย้อนหลัง
└── ☰ เพิ่มเติม  คลังท่า, จัดการโปรแกรม, คำนวณ 1RM, เหรียญ, ข้อมูล, Face ID, แจ้งเตือน, ภาษา

หัวหน้าจอ: ชื่อหน้า + วันที่ (แตะเพื่อเปิดปฏิทิน)   ← ไม่มีปุ่มอื่น
```

## เฟส 1 — ควรทำก่อน (กระทบการใช้ทุกวัน)

### 1.1 การ์ด "วันนี้" บนหน้าเวท
- **ปัญหา:** วันพฤหัสตามตารางคือตีแบด แต่บอกแค่ "Up next" ตัวเล็กในการ์ดแบด ต้องหาเอง
- **ทำ:**
  - การ์ดใหญ่บนสุดใต้แถบสัปดาห์: ชื่อสิ่งที่ต้องทำวันนี้ตามตาราง + สรุปสั้น (จำนวนท่า / กลุ่มกล้าม / ระยะวิ่ง)
  - ปุ่มเดียวตามประเภทวัน: `▶ เริ่ม Pull A` · `🏸 บันทึกตีแบด` · `🏃 บันทึกวิ่ง 10 km` · วันพัก = "วันพัก 😴" + ลิงก์เล็ก "ออกนอกตาราง"
  - ทำไปแล้ววันนี้ → การ์ดเปลี่ยนเป็นสรุป (✓ Pull A · 7 ท่า · 4,200 kg)
  - กำลังเล่นค้างอยู่ → ปุ่มเป็น `กลับไปเล่นต่อ`
- **เสร็จเมื่อ:** เปิดหน้าเวทแล้วกดเริ่มได้ใน 1 แตะ โดยไม่ต้องเลื่อน

### 1.2 หน้าอาหาร: เน้นมื้อถัดไป ย่อมื้อที่กินแล้ว
- **ปัญหา:** 7 มื้อหน้าตาเหมือนกัน มื้อที่กินแล้วยังกางเต็ม หน้ายาว 2 จอ
- **ทำ:**
  - การ์ด **มื้อถัดไป** เด่นใต้แถบแคล/โปรตีน พร้อมปุ่ม `✓ กินแล้ว`
  - มื้อที่ติ๊กแล้วย่อเหลือ 1 บรรทัด (เวลา · ชื่อ · ✓) แตะเพื่อกาง/ยกเลิก
  - มื้อที่เลยเวลาแต่ยังไม่ติ๊ก ขึ้นป้าย "เลยเวลา" สีส้ม
  - ย้ายประวัติ + กราฟอาหาร ไปแท็บสถิติ › ร่างกาย
- **เสร็จเมื่อ:** หน้าอาหารของวันปกติไม่เกิน ~1 จอ

### 1.3 ทางไปซ้ำกัน → เหลือชุดเดียว
- **ปัญหา:** ☰ มุมซ้าย, แท็บ "เพิ่มเติม", ปุ่ม ↻ / TH มุมขวา ชี้ที่เดียวกัน
- **ทำ:**
  - เอาปุ่ม ☰ มุมซ้ายออก (หรือเก็บไว้เป็นทางลัดเดียวกับแท็บ ☰ — เลือกอย่างเดียว)
  - แท็บ ☰ เพิ่มเติม รวมทุกเมนูที่อยู่ใน drawer: คลังท่า, จัดการโปรแกรม, 1RM, เหรียญ, ภาษา, ข้อมูล, Face ID, แจ้งเตือน
  - เอาปุ่ม ↻ และ TH ออกจากหัวหน้าจอ (รีเฟรช = ดึงลง, ภาษา = ในเพิ่มเติม)
- **เสร็จเมื่อ:** ทุกฟีเจอร์มีทางเข้าที่เดียว หัวหน้าจอมีแค่ชื่อหน้า + วันที่

### 1.4 เอาบรรทัดตรวจจอออก
- ลบบรรทัด `vp 430×932 · …` ในหน้าเพิ่มเติม (เป็นเครื่องมือดีบั๊ก)

## เฟส 2 — อ่านง่ายและเป็นชุดเดียวกัน

### 2.1 ระบบตัวอักษร
- **ปัญหา:** ปุ่มตัวพิมพ์ใหญ่ห่าง ๆ แบบ mono (SHARE, CLEAR TODAY, LOG BODY) ปนกับตัวหนา iOS
- **ทำ:**
  - ปุ่ม/ป้าย/หัวข้อ: ฟอนต์ระบบ (SF / IBM Plex Sans Thai) ตัวปกติ ไม่ใช่ตัวพิมพ์ใหญ่ทั้งหมด
  - ตัวเลข (kg, เซ็ต, เวลา): IBM Plex Mono เท่านั้น
  - ลำดับขนาด: หัวหน้า 28 · หัวข้อส่วน 20 · เนื้อหา 15 · รอง 13 · คำอธิบาย 12

### 2.2 ไอคอนชุดเดียว
- แทนอีโมจิสี (🍽️ 🏋️ 📈 🔩 🔗) ด้วยไอคอนเส้นชุดเดียว (เช่น SF Symbols-style SVG) สีครีม
- ตัวละครพิกเซลเก็บไว้เฉพาะการ์ดเลเวล / แถบพัก

### 2.3 หน้าสถิติแบ่งแท็บย่อย
- **ปัญหา:** 7 ส่วนต่อกัน ยาวเกือบ 3 จอ
- **ทำ:** ปุ่มสลับบนสุด `การฝึก | ร่างกาย`
  - การฝึก: ภาพรวม → การฟื้นตัว → วอลุ่ม → เซ็ตต่อกล้าม → 1RM → ความก้าวหน้าต่อท่า
  - ร่างกาย: น้ำหนัก/มวลกล้าม/ไขมัน → โภชนาการย้อนหลัง (ย้ายมาจากหน้าอาหาร)
- จำแท็บย่อยที่เลือกล่าสุด

### 2.4 การ์ดโปรแกรมให้โล่ง
- เอารายชื่อท่า 3 บรรทัดออก เหลือ: ชื่อ · จำนวนท่า · กลุ่มกล้าม · ล่าสุด
- รายละเอียดดูในแผ่นโปรแกรม (มีอยู่แล้ว)

### 2.5 การ์ดเลเวลย่อ
- เปลี่ยนเป็นแถบเตี้ย (ตัวละครเล็ก + Lv + หลอด XP) ใต้การ์ดวันนี้
- เลเวลอัปยังโชว์ animation + toast เหมือนเดิม
